GEARSHIFTMEDIA GLOBAL VISITOR COUNTER

This version uses Page Views API for a shared counter that works with static GitHub Pages.
All pages record to one shared path and then display the same total.
Site identifier: gearshiftmedia.github.io

After uploading all files to GitHub Pages, open the site from different devices/networks.
The number should update from the shared API instead of staying at 00 or 1.
